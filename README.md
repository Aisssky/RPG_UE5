# UE5MOBA_Demo


> **4 人联机 PvE MOBA** — 从五位茶道英雄中选择你的角色，与队友推兵线、拆防御塔、击败 AI 敌方英雄，最终摧毁敌方基地。

基于 **Unreal Engine 5.6** + **Gameplay Ability System ** 构建，Dedicated Server 网络架构。

## 技术栈

| 模块 | 用途 |
|---|---|
| `GameplayAbilitySystem` | GA / GE / AttributeSet / GC / MMC / Task / Cooldown / Cost |
| `GameplayTags` | 技能标签、事件标签、状态标签统一管理 |
| `GameplayTasks` | 异步技能任务 |
| `EnhancedInput` | 增强输入系统 |
| `UMG` | UI 控件与属性绑定 |
| `AIModule` | 敌方 AI 行为树 |
| `OnlineSubsystemNull` | 局域网联机 |
